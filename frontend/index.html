    How it works

    1. Hold an Agent ID. Agent ID is a non-transferable on-chain identity — one per user.
    2. Vouch once. The contract checks your Agent ID balance on-chain before accepting your vouch.
    3. One vouch each. A holder can vouch for exactly one address, forever. No duplicates, no take-backs.
